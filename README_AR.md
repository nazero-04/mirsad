# مرصاد — نسخة جاهزة لـ GitHub Pages

مرصاد نموذج تجريبي لرصد المخلفات المرئية على سطح الماء. يتضمن نموذج YOLOv8n المدرّب في تجربة المشروع، ويشغّله داخل المتصفح بصيغة ONNX. استعان الفريق بأدوات الذكاء الاصطناعي في تطوير المشروع، مع الاحتفاظ بنسبة البيانات والمكتبات إلى مؤلفيها.

## رفع الموقع من المتصفح

1. أنشئي حسابك على [GitHub](https://github.com/signup) وأكملي تأكيد بريدك.
2. فكّي ضغط `Mirsad_GitHub_Pages.zip`. ستجدين مجلدًا اسمه `mirsad`.
3. أنشئي مستودعًا جديدًا باسم `mirsad`، واختاري **Public**. فعّلي **Add a README file** لإنشاء الفرع `main`، ثم اختاري **Create repository**.
4. افتحي المستودع واختاري **Add file → Upload files**.
5. افتحي مجلد `mirsad` على جهازك واسحبي **محتوياته** إلى صفحة الرفع: الملفات ومجلدات `assets` و`lib` و`vendor`. ارفعي المحتويات إلى جذر المستودع؛ يجب أن يظهر `index.html` مباشرة فيه. لا ترفعي ملف ZIP نفسه، ولا تضعي مجلد `mirsad` كاملًا داخل مجلد آخر بالمستودع.
6. انتظري اكتمال رفع الملفات، ثم احفظيها باستخدام **Commit changes** على الفرع `main`. تحققي من وجود `.nojekyll` مع `index.html`.
7. افتحي **Settings → Pages**. تحت **Build and deployment** اختاري **Source: Deploy from a branch**، ثم **main** و**/(root)**، واضغطي **Save**.
8. انتظري اكتمال النشر، ثم افتحي الرابط الذي تعرضه صفحة **Pages**. سيكون عادةً `https://USERNAME.github.io/mirsad/`، حيث `USERNAME` اسم حسابك.
9. جرّبي إحدى صور العينات، ثم زر **مشاركة المنصة**. يأخذ الرابط ورمز QR عنوان موقعك الحالي تلقائيًا. افتحي رابط HTTPS للسماح بالكاميرا وتحديد الموقع.

هذه النسخة لا تحتاج إلى تثبيت Python أو برامج تطوير على جهازك. لا تحتاج أيضًا إلى مفتاح API لتشغيل الموديل.

## ما الذي يعمل؟

- رفع صورة أو التقاطها بالكاميرا، وتشغيل الكشف داخل المتصفح، ثم رسم مربعات المخلفات المرصودة.
- تحديد موقع البلاغ، ومراجعة النتيجة، وحفظ البلاغ محليًا وتصدير التقارير.
- عرض نتائج التدريب والاختبار، مع أربع صور تجريبية من مجموعة الاختبار.
- مشاركة رابط الموقع ورمز QR.

## نتائج الاختبار

تأتي القيم التالية من ملفات تقييم المشروع على **548 صورة اختبار**. لم نعد حسابها عند تجهيز نسخة GitHub.

| المقياس | النتيجة |
| --- | ---: |
| صحة قرار وجود مخلفات في الصورة — Accuracy | 96.72% |
| Precision لقرار الصورة | 97.78% |
| Recall لقرار الصورة | 97.25% |
| F1 لقرار الصورة | 97.51% |
| mAP@50 لكشف الأجسام | 88.75% |
| mAP@50–95 لكشف الأجسام | 52.85% |

إعدادات الاستخدام: صورة بحجم 640 × 640 بعد الحفاظ على النسب وإضافة الهوامش، وعتبة ثقة 0.339، وعتبة تداخل NMS مقدارها 0.7. تبقى ملفات النتائج الأصلية متاحة في `assets`.

## نطاق النسخة

- يرصد الموديل المخلفات المرئية من فئة التدريب. عدم ظهور اكتشاف لا يثبت خلو الماء من الملوثات الكيميائية أو الزيوت.
- مصدر التدريب صور سطح الماء من مركبة سطحية؛ تقييم صور الدرون الجوية يحتاج إلى اختبار منفصل.
- البلاغات محفوظة في الجهاز والمتصفح المستخدمين؛ لا توجد قاعدة بيانات مشتركة أو عملية إرسال فعلية إلى درون.
- تغيير نطاق الموقع لا ينقل البلاغات المحفوظة في المتصفح من النطاق السابق.
- تحتاج الخريطة إلى اتصال بالإنترنت. يجري تحليل الصور داخل المتصفح؛ سرعة الجهاز تؤثر في زمن التحليل.
- قد يخطئ النموذج. تتضمن العينة الرابعة إنذارًا كاذبًا محفوظًا كما ظهر في التقييم الأصلي.
