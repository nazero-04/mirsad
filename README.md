# مرصاد | Mirsad

نسخة جاهزة للنشر على GitHub Pages، دون تثبيت برامج على جهازك.

## طريقة النشر

1. أنشئي حسابًا شخصيًا مجانيًا عبر https://github.com/signup وأكملي التحقق من البريد.
2. بعد تسجيل الدخول، افتحي https://github.com/new . اكتبي `mirsad` في Repository name واختاري Public ثم Create repository.
3. فكّي ضغط الحزمة على جهازك. افتحي مجلد `mirsad` الناتج.
4. من المستودع اختاري Upload files أو uploading an existing file. اسحبي **محتويات** المجلد إلى صفحة الرفع: الملفات والمجلدات معًا. لا ترفعي ملف ZIP، ولا تضعي مجلد mirsad إضافيًا داخل المستودع.
5. احفظي الملفات باستخدام Commit changes. يجب أن يظهر `index.html` مباشرة في المستوى الأول للمستودع، وبجواره `assets` و`vendor` و`lib`.
6. افتحي Settings ثم Pages. تحت Source اختاري Deploy from a branch. اختاري الفرع `main` والمجلد `/(root)` ثم Save.
7. انتظري اكتمال النشر، ثم افتحي الرابط الذي يعرضه GitHub في صفحة Pages. إذا طلبت الخدمة التحقق من البريد، أكمليه أولًا.

يتكيّف زر المشاركة ورمز QR مع عنوان الموقع المنشور تلقائيًا، بما في ذلك اسم المستودع في المسار. لا تحتاجين تعديل اسم المستخدم داخل الكود.

## ماذا يعمل؟

- اختيار صورة أو التقاطها بالكاميرا، وتحليلها داخل المتصفح.
- كشف المخلفات المرئية باستخدام نموذج YOLOv8n المدرّب، مع مربعات ودرجات ثقة.
- تحديد موقع البلاغ على الخريطة أو بإدخال الإحداثيات.
- حفظ البلاغ بعد المراجعة وتنزيله، وعرض نتائج التدريب والاختبار.
- البلاغات محلية لهذا المتصفح؛ لا توجد قاعدة مشتركة بين أجهزة الفريق. مهمة الدرون محاكاة ولا ترسل أوامر إلى درون فعلي.

## البيانات والتقييم

النموذج دُرّب لمدة 20 دورة في Google Colab. مجموعة الاختبار تضم 548 صورة. النتائج من ملفات المشروع الأصلية:

| المؤشر | القيمة |
|---|---:|
| Accuracy على مستوى الصورة | 96.72% |
| Precision على مستوى الصورة | 97.78% |
| Recall على مستوى الصورة | 97.25% |
| F1 على مستوى الصورة | 97.51% |
| mAP@50 لكشف الأجسام | 88.75% |
| mAP@50:95 لكشف الأجسام | 52.85% |
| إنذارات خاطئة | 8 |
| صور موجبة فات رصدها | 10 |

عتبة الثقة 0.339 مستمدة من منحنى التحقق، وNMS IoU تساوي 0.7. لا تمثل نتائج وجود المخلفات اختبارًا لجودة المياه الكيميائية. البيانات ذات تصوير سطحي؛ يلزم تقييم مستقل للصور الجوية من الدرون.

أعدّ المشروع الكود والواجهة بمساعدة الذكاء الاصطناعي، ونفّذت لانا التدريب والاختبار في Colab. يجب أن يطابق وصف المساهمات الفعلية وقواعد الإفصاح متطلبات الهاكاثون.

## الملفات المهمة

- `index.html`: الواجهة.
- `app.js`: الصور والموقع والبلاغات والرسوم والمشاركة.
- `inference.js`: تجهيز الصورة وتشغيل النموذج وتحديد المربعات.
- `assets/mirsad.onnx`: نسخة النموذج التي تعمل داخل المتصفح.
- `assets/data.json`: نتائج التدريب والتقييم الحقيقية.
- ملفات التراخيص داخل `vendor` و`lib` محفوظة مع المكتبات.
